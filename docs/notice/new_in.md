## 考核范围

=== "夏考同学"

    编程语言语法的基本运用及思维题。

    **建议学习路径：**

    > 学习 C++ / Java / Python（推荐 C++） → 基本 STL

=== "春考 / 夏考 / 专升本 / 27级同学"

    编程语言的熟练运用、思维题以及基本算法题。

    **建议学习路径：**

    > 学习 C++ / Java / Python（推荐 C++） → 基本 STL → 简单数据结构（栈、队列、链表） → 简单算法（枚举、排序、双指针）
