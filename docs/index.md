## 📖 关于我们

ICPC实验室（逸工作室）是由计算机系负责的全校性学生学术科技组织，于 2018 年成立，是全校竞赛类学生组织之一。

我们主要组织我校同学参加以下赛事：

- **蓝桥杯** —— 软件类专业人才大赛
- **ICPC / CCPC** —— 国际/中国大学生程序设计竞赛
- **软件杯** —— 中国大学生软件设计大奖赛
- **CSP / 天梯赛** —— CCF 计算机软件能力认证

> 在丰富同学们课余生活的同时，提高个人技术水平，营造校园科技创新氛围。

## 🎯 我们的理念

=== "以赛促学"
    通过高水平竞赛倒逼学习动力，在实战中检验知识盲区，让成长看得见。

=== "项目驱动"
    开发部以真实项目为载体，从需求分析到上线部署全流程参与，培养工程能力。

=== "互助共进"
    学长带学弟、队友互 Code Review。没有人会掉队，每个人都能找到自己的节奏。
