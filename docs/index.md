=== "日常训练"
    - 周中：自学 + 小组打卡刷题（10-20 题/周）
    - 周末：线下集训 2-4 小时，专题讲解 + 模拟赛
    - 定期：代码分享会、读书会、技术讲座

=== "集训营"
    赛前 1-2 个月开启封闭式冲刺营，教练出题、模拟、复盘。蓝桥杯、ICPC 区域赛前必开。

=== "考核机制"
    - 入门：参加集训营并完成基础算法考核
    - 进阶：在校级选拔赛中取得稳定成绩
    - 高阶：作为主力代表学校参加省级以上赛事

## 📖 关于我们

ICPC实验室（逸工作室）是由计算机系负责的全校性学生学术科技组织，于 2018 年成立，是全校竞赛类学生组织之一。

我们的使命是组织和培训我校同学参加**蓝桥杯**、**软件杯**、**ICPC/CCPC**、**CSP/天梯赛** 等高水平大学生课外学术科技作品竞赛。在丰富同学们课余生活的同时，提高个人技术水平，营造校园科技创新氛围。

## 🎯 我们的理念

=== "以赛促学"
    通过高水平竞赛倒逼学习动力，在实战中检验知识盲区，让成长看得见。

=== "项目驱动"
    开发部以真实项目为载体，从需求分析到上线部署全流程参与，培养工程能力。

=== "互助共进"
    学长带学弟、队友互 Code Review。没有人会掉队，每个人都能找到自己的节奏。
