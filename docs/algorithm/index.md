# 算法竞赛介绍

## 什么是算法竞赛？

算法竞赛中，参赛者通过解决一系列复杂的计算机编程问题来展示他们的**算法设计**、**编程实现**和**问题解决能力**。这些问题通常涵盖了计算机科学中的各个领域，如图论、动态规划、数据结构等。

### 以 ICPC 赛制为例

- 队内合作（3人一队），上机写程序提交给在线评测系统，当场返回结果
- 排名按照**通过题目数**由高到低；题目相同则按**罚时**由低到高
- 罚时 = 所有通过题目的提交时间之和 + 失败提交次数 × 20 分钟

## 为什么要参加算法竞赛？

=== "提升硬核实力"
    算法是编程的灵魂。竞赛训练让你写出更高效、更优雅的代码。

=== "助力考研就业"
    - 考研复试：算法奖项 = 硬核加分项
    - 求职大厂：算法题是必考环节，竞赛经验让你游刃有余

=== "培养团队协作"
    ICPC 三人组队，考验沟通、分工与心态，这些能力受益终身。

=== "结识同好"
    和一群热爱编程的伙伴一起奋斗，大学生活不再孤单。
