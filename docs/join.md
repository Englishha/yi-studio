## 📚 考核范围

=== "夏考同学"
    编程语言语法的基本运用及思维题。

    **建议学习路径：**

    > 学习一门编程语言（C++ / Java / Python，推荐 C++）→ 基本 STL

=== "春考 / 专升本同学"
    编程语言的熟练运用、思维题以及基本算法题。

    **建议学习路径：**

    > 学习 C++ / Java / Python（推荐 C++）→ 基本 STL → 简单数据结构 → 简单算法

!!! tip "零基础？别怕！"
    完全零基础的同学也可以报名。我们会在集训期间从零开始带你入门，只要你有热情和耐心。
