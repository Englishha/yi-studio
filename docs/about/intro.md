# 关于我们

## 社团简介

逸工作室（ICPC实验室）是由计算机系负责的全校性学生学术科技组织，于 2018 年成立，是全校竞赛类学生组织之一。

我们的使命是组织和培训我校同学参加**蓝桥杯**、**软件杯**、**ICPC/CCPC** 等高水平大学生课外学术科技作品竞赛。在丰富同学们课余生活的同时，提高个人技术水平，营造校园科技创新氛围。

## 我们的优势

- **教练指导**：专业教师带队，提供系统化训练方案
- **传承体系**：学长带学弟的互助机制，经验代代相传
- **设备充足**：工作室配备专用电脑，满足开发与训练需求
- **实战机会**：定期组织校内模拟赛 + 校外同步赛
- **资源共享**：内部题库、书单、真题解析库全员开放
