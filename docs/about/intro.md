## 社团简介

逸工作室（ICPC实验室）是由计算机系负责的全校性学生学术科技组织，于 **2018 年**成立，是全校竞赛类学生组织之一。

我们的使命是组织和培训我校同学参加**蓝桥杯**、**软件杯**、**ICPC/CCPC**、**CSP/天梯赛** 等高水平大学生课外学术科技作品竞赛。在丰富同学们课余生活的同时，提高个人技术水平，营造校园科技创新氛围。

## 我们的理念

=== "以赛促学"
    通过高水平竞赛倒逼学习动力，在实战中检验知识盲区，让成长看得见。

=== "项目驱动"
    开发部以真实项目为载体，从需求分析到上线部署全流程参与，培养工程能力。

=== "互助共进"
    学长带学弟、队友互 Code Review。没有人会掉队，每个人都能找到自己的节奏。
