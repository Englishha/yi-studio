# 部门架构

## 竞赛部门（算法部）

<figure markdown>
  <div class="feature-icon" style="font-size:3rem;">🤖</div>
</figure>

### 我们做什么

竞赛部门主要负责培训部员的算法能力，组织参加各类算法比赛。算法是找工作和考研必备的核心技能之一。

### 我们参加的赛事

- **蓝桥杯**（省赛 / 国赛）
- **ICPC / CCPC**（区域赛 / 省赛）
- **CSP-J/S** / 天梯赛

### 你将收获

- 系统掌握基础算法与数据结构
- 参与 3 人组队的 ICPC 赛制实战
- 参加校级、省级、国家级竞赛
- 考研复试 / 求职简历亮点

### 训练内容

=== "初级"
    - C++ / Java / Python 基础语法
    - STL 使用
    - 枚举、排序、双指针、前缀和

=== "中级"
    - DFS / BFS 搜索
    - 最短路径（Dijkstra / SPFA / Floyd）
    - 动态规划（线性 / 区间 / 状态压缩）
    - 数论基础

=== "高级"
    - 高级图论（网络流、LCA、二分图）
    - 高级数据结构（线段树、树状数组、平衡树）
    - 字符串算法（KMP、Trie、AC 自动机）

## 开发部门

<figure markdown>
  <div class="feature-icon" style="font-size:3rem;">💻</div>
</figure>

### 我们做什么

开发部门聚焦全栈开发与软件工程。工作室设备充足，通过**团队协作**完成实际项目，积极参加"软件杯"等综合性赛事。

### 技术栈方向

| 方向 | 核心技术 |
| --- | --- |
| **前端** | HTML / CSS / JavaScript / Vue / React |
| **后端** | Java Spring Boot / Node.js / Python Django / Go |
| **数据库** | MySQL / Redis / MongoDB |
| **DevOps** | Git / Docker / Linux / CI/CD |

### 你将收获

- 完整的项目开发经验（从需求到上线）
- 熟悉 Git 协作与代码规范
- 参加软件杯等开发类竞赛
- 考研复试 / 求职的作品 portfolio

---

## 部门对比

| 维度 | 竞赛部门 | 开发部门 |
| --- | --- | --- |
| **核心目标** | 算法竞赛获奖 | 项目开发能力 |
| **比赛类型** | ICPC / 蓝桥杯 | 软件杯 / 互联网+ |
| **技能侧重** | 算法思维、编码速度 | 工程化、协作沟通 |
| **学习周期** | 长（持续训练） | 中（项目驱动） |
| **适合人群** | 数学/逻辑兴趣强 | 喜欢做产品、动手实践 |

!!! tip "两个部门可以兼修"
    我们鼓励成员同时参与两个部门的活动。算法功底 + 开发能力 = 硬核竞争力。
